# 网站实况数据

`live.contract.json` 给通用读取器声明数据、段落及公开方式；`live.snapshot.json` 是带源时刻的公开初始快照。

构建、成功发布和访客查询分别更新各自的数据，保留源时刻。新工作副本默认写到忽略的 `.live/`。正式工作副本按 [README](../README.md) 挂 `.publish/private/live-project.json`，其中 `public` 和 `owner` 指向登记的两个绝对路径。本人份额外提供本地成品登记和专用入口汇总；“在电脑上打开”由共享后端按实际文件提供。

完整成品缓存命中时，保留上次组装时刻和完整组装耗时，不把只核对成品的耗时冒充组装。

普通近七天查询可更新访客快照。已有巡检调用查询工具的 `--monitor-sources` 分支，按登记路径检查两份快照，取数不足一小时时沿用。打开网页本身不会触发取数。未在公开成品找到的路由合为“其他地址”，编号和 IP 不进快照。打开次数按信标计，爬虫量只是图片桶中声称对应身份的请求下限。[访客日志](visitor-logs.md)

规模快照取自已登记主仓及其配套源的原有计数，保持原计数时刻；不是新版本成品的字数。正式页按本地新版站点地图，HTML 文件总数另列，含跳转和功能页。容量值以字节提供，显示按 1024 进位写 GB、MB、KB。

当前 [项目合同](live.contract.json) 登记三个任务、零个名下技能，`bindings_complete` 为 `true`。运行状态由 PCConfig 按当前任务来源供给。每次内容更新仍执行 [实况七项](update.md#九实况每次过的-7-条)。
