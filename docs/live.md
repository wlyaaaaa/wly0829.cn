# 网站实况数据

`live.contract.json` 给通用读取器声明数据、段落及公开方式；`live.snapshot.json` 是带源时刻的公开初始快照。

现有构建、成功发布和普通近七天访客查询会各自写一份小输出，并保留各项原始时刻。输出默认在忽略的 `.live/`；本机可通过私有映射 `.publish/private/live-project.json` 指定 `public` 和 `owner` 两个文件。本人份包含本地成品登记及专用入口汇总，公开份不包含这些值。本地成品只声明 exists 来源，由共享后端提供“在电脑上打开”。

完整成品缓存命中时，保留上次组装时刻和完整组装耗时，不把只核对成品的耗时冒充组装。

访客只随按需查询刷新，没有接入每日任务；按需更新流程尚未确定，不把手工查询说成每晚自动更新。网页打开不会启动查询。未在公开成品中找到的地址合并为“其他地址”，浏览器编号和 IP 不进入快照。数组从 records 入口展开；打开次数不等于正文阅读，爬虫数只是图片桶中声称对应身份的请求下限。

规模快照取自已登记主仓及其配套源的原有计数，保持原计数时刻；不是新版本成品的字数。正式页按本地新版站点地图，HTML 文件总数另列，含跳转和功能页。容量值以字节提供，显示按 1024 进位写 GB、MB、KB。

名下技能已确认为空；任务声明保留三个稳定 ID。EdgeOne 工作流尚待补入统一目录并通过 `/tasks` 回读，故 `bindings_complete` 保持 false，任务总数返回 null。
