# 布局与交互

## 项目和技能讲解页／画里的按钮

先在画面里找适合按钮的位置。木桌、地面、书页、搪瓷面都可以承接按钮，选场景本来就有的材质和配色。正文和关键物件周围留开，多枚按钮各自能认清。

给生图的提示写清按钮落在哪、场景材质怎样延续。画内用到的书、告示牌和白板要有稿上已有的内容，或给按钮实际使用。暂时没有按钮时照常把场景画完整。已有空书、空牌或突兀垫板时，能安放现有文字或按钮就用起来，放不了就带原图局部重画。

点击由网页的链接承担，按钮随插画一起缩放。封面有「看本项目实况」时，取同页按钮的形制和色调，实际打开电脑版和手机竖屏看落点与可读性。

默认用画内左下的现成材质。需要挪动按钮组时，对应图节可记 `buttonArea: [左距, 底距, 可用宽度]`，数字按画幅百分比填写。

## 卡片跳转／主要去处与多指向

卡片有明确主要去处时可整卡跳转，其他文字链接和右上箭头保留各自去处；多指向且没有主要去处时，只用具体文字跳转。

## 网站占位区／允许留空的条件

禁令：网站已经安排内容的占位区域，除明确预留实时数据的位置外，不要空着。

## 首页开场／播放与等待

首页每次打开都演“从白纸晕开”开场，第一帧和样子保持，只做提速；开场前白屏等待可到两秒，不改成静态画兜底或取消开场。设备卡顿时提供处理办法，不因别的设备可能卡就默认撤掉。

## 实况入口和本人操作

现行实况入口是 `/live/`，前端在 `site-v2/live/`。页面用全站的 `width=1440` 视口，手机按电脑版整页等比缩小，双指放大照常可用。以现役主页和各详情页为版式依据，沿用全站书法标题、水彩插画、浅绿卡片和常开动效。

本人设备按配对状态和服务端允许的动作显示「我知道了」「不办了」「晚点提醒」「关掉」或「复制给 AI」。实际适用条目和动作请求见现役 `site-v2/live/_lib/live-ui.js`、`live-client.js` 与 PCConfig 的 `docs/runtime/dashboard-api-contract.md`。公开版展示公开数据，个人操作及处理条件由同一现行合同决定。

旧驾驶舱的卡片布局、复制范围、状态栏与窄屏重排属于旧版设计记录。旧地址兼容见 [发布与扫描](../publish-and-scan.md)。

## 插画／昼夜

只有首页的画跟着昼夜变。其他页面的插画和小鸟（驾驶舱、怎么协作、授权与状态、项目、技能、规则等）一律固定白天的样子：不变暗、不偏蓝偏暖，夜里屏幕和灯不另加亮，小鸟不睡。驾驶舱“今天的河”同样固定白天，不随时间切换昼夜调色。

## 实况首屏与详情

首屏让人一眼看出现在的情况以及有没有事要本人处理。分块和详情以 `site-v2/live/` 的现役页面为准。
