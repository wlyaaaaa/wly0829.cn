owner: E:\.agents

只在用到 Antigravity 桌面版特有机制时读；共同原则见其他专题，选型看模型清单，授权看用户授权。在这里接的钩子、技能、MCP、设置，另两家也要接，例外见能力与运行方式“三家一起装”。下面写“待实测”的，都要等 Antigravity 额度恢复后用真对话核对；核对前不猜，照写明的退路办。

入口和规则加载

  • 活动版约法和导航由规则发布器写进 Antigravity 读的全局规则位置（插件 personal-env 的规则目录，具体落点以发布器为准），加载时已在上下文；后面接着 Antigravity 入口结尾“Gemini 容易错的（主持时）”那段。专题按文中当版的绝对路径读。规则源码 E:\.agents\AI-CHARTER.md 不是活动规则，插件规则不引用它；插件里的规则入口只由发布器写，PCConfig 的安装器不写同一份。
  • Antigravity 对规则有两条硬限制：展开后单个规则文件最多 24,000 字节，超出按行截掉；全局和常驻规则共用约 20,000 token 的预算，超了会把部分正文降成文件指针。所以约法和入口结尾分文件放，约法太长时按章节切成几份，每份都随版本核对；约法要整段进上下文，被截断或降成文件指针就算入口没装好。发布器只估算自己部署的全局规则（目前为 AGENTS.md、personal-env-e-rules-002.md 和 personal-env-e-rules-ending.md）：每份的 UTF-8 字节数除以 3 后向上取整再相加，后两份先扣除 YAML 触发条件。合计超过 20,000 不发：把约法里的细则挪进专题、留一句指路，或删重复，不为凑数删本人要的意思。
  • 项目里的 AGENTS.md、GEMINI.md 和 .agents/rules/*.md 会沿工作目录往上加载。在规则源码仓库 E:\.agents 里工作时，根目录 AGENTS.md 提供短项目说明，约法源码 AI-CHARTER.md 不会被自动发现；以全局规则里的活动版为准，源码只是待审材料。
  • Antigravity 没有原生的压缩前后事件；长对话压缩后规则是否原样还在，待实测。

身份

Antigravity 现在是普通智能体，不是最高权限智能体（本人 2026-11-18 定：先不登记）。它的桌面程序没有 Windows 包族，也没有代码签名，密码中心认不准是不是它本身；等 Google 出签名版，或查到可信的安装来源，再按用户授权登记。在那之前：

  • 不冒充 Claude、Codex 的桌面身份，不借它们的进程链、环境变量或会话号。agy 命令行、包装器起的 agy 子任务同样没有桌面身份。
  • 要用私人资料时，它作为根会话照个人资料与数据处理“怎么解锁”办：自己判断要不要发起解锁，要就走现有解锁入口 VerifyPersonalEnvironment，请本人四选一验证一次，验证通过、资料能读之后再用（本人 2026-11-19 00:20）。它不是最高权限智能体，不能用 Runtime 因子自己锁、自己恢复。密码中心凭据没有受信任 AI 的免验证待遇，照用户授权办。本人要求开始、验收或重试无限制授权时，照用户授权直接打开本人接管入口 Invoke-OwnerTakeover.ps1 -Operation Open，由本人验证。普通技术活照常。

思考档位和原生子代理

  • 本家（Gemini）一律用原生子代理，型号和档位照模型清单。
  • 原生入口：invoke_subagent 派一组任务（可选沿用当前目录、隔离的 Git 工作树或共享目录，默认从独立上下文开始，可以并发）；define_subagent 在对话里临时定义角色，可复用的角色文件按 Google 文档放：工作区 .agents/agents/<name>.md（或 <name>/agent.md），全局 ~/.gemini/config/agents/，插件 <插件根>/agents/（子代理文档、插件文档）；manage_subagents 列出、停止；send_message 给运行中的子代理续派指示。
  • 档位能指定（本人 2026-11-19 说测过）。型号按角色文件的 model 选类别：子代理文档列 inherit、flash、pro，插件文档另列 flash_lite；Google 文档没写各类别对应 Neon、Hydrogen 哪一款，本机核对等额度恢复，核对前不把 pro 当成 Neon。定不住清单要的型号怎么办，到时候问本人。
  • 原生并发上限待实测。名额满了，要紧的活先问本人等不等；不要紧的照清单换能胜任的。成组开工的 /swarm 只在本人要时用。

派别家（共用包装器）

  • GPT 和 Claude 的型号只经共用包装器 E:\.agents\tools\Invoke-ClaudeGptChild.ps1 派，显式带 -ParentHarness Antigravity -SessionId '<完整对话号>'（对话号用 Antigravity 的完整 conversationId，不截短）；-Model、-Effort 照模型清单写明，不靠默认。派之前思考摘要写一句“我要派 Opus 5.5（xhigh）”这样的话（型号写正式名，档位只写一次），途中和最后一条也说一声，型号和档位照这样写。
  • 派 Astra 默认禁止；确需派，由根会话按模型清单 routing.astra_dispatch 查授权边界，再用共用包装器填报 -AstraBasis 与 -AstraReason。子代理一律交回主持。原线程接续按派发说明。
  • 默认结果目录是 E:\Cache\Antigravity\Temp\<对话号前 8 位>\gpt-children，子任务交回写在它任务目录的 to-parent.md。命令、单子模板、怎么等、怎么验收见 dispatch-work 技能；全部参数见派发说明；修改仓库用任务专用工作树。
  • Claude 订阅那一路全机共用 3 个名额。名额满了，要紧的活先问本人等不等，问的同时做不依赖它的；不要紧的照清单换能胜任的。
  • 派出的型号调不动，按实际原因处理：登录失效先修好，再接回原任务；回执说这家用不了（订阅失效、额度用完、账号用不了这个型号），照模型清单那一行“这家用不了交谁”换人接着做（那一行列的同家别的池子、免费后备或别家），告诉本人。经包装器实际派出的 Claude 调不通时，按模型清单 model_unavailable 查 Antigravity 的同一型号、同一档位（原通道连线重试走完仍不通也试），能用就自动改走、回执写明；没有同档或那边也不通，回执保留原来的失败原因。派前已有未到期的 Claude 拒绝记录时，照Claude 适配走同型号、同档位的后备。短时限流、满载交包装器自动重试，不算用不了。
  • 包装器起的子任务没有桌面身份，要密码中心桌面身份的步骤不交给它们。
  • 不碰桌面 Claude、Codex：不启动、关闭、操作它们的界面，不读写它们的会话和设置；用它们的型号只走包装器。

钩子

钩子挂在插件 personal-env 的 hooks.json，由 PCConfig 的安装器管理，程序做法见运维说明，这里只写要的结果。两条厂商事实决定了怎么用：钩子脚本出错（非零退出）时 Antigravity 会忽略它、照常往下跑，所以钩子只递信息和提醒，不当身份门，拦东西要靠它正常返回的拒绝；PreInvocation 每次模型调用前都触发，一条本人消息可能触发好几次，原话和本人消息清单按真实消息去重，不能当成本人说了好几遍。

事件 要递什么 现在
SessionStart 核对规则版本：一致给一行回执，不一致给活动版的路径；桌面根对话提醒标“能／不能给外人看”；递工程和《他要什么》的位置 程序已做，装上后生效；根对话身份稍晚才认出时，由叫模型前补上提醒
PreInvocation 核实后存档本人原话、递本轮本人消息清单；对话里出现新的压缩摘要步骤、摘要里没有工程和《他要什么》的位置时补一次（没有压缩事件，见压缩前后） 来源从本地桌面对话数据库核对，钩子输入自身不证明来源；档位仍拿不到。北京时间、资料状态和型号照常
PreToolUse 自带生图只给 GPT 额度真用完的本单后备；要登录的网页提醒走包装器；派帮手（invoke_subagent）时补北京时间、资料状态、型号来源和工程位置 默认拦 generate_image 和明确点名的 image-generator 子代理；包装器确认 GPT 有未到期的实际拒绝记录，或在当前任务收到 GPT 结构化 usageLimitExceeded 且可安全重派时，放行生图后备；登录网页改在每轮首次调用时提醒
PostToolUse 只记下工具的宿主报错，下一次调用前一起递；正常返回不重复提示，这个事件也拿不到成功输出 程序已做，装上后生效
Stop 收工只查 3 样：资料锁拦住了还没处理、共用包装器派的 GPT 子任务在跑却没挂 Watch、给本人的回复主要是英文；首次命中请宿主补一轮，第二次只提示；正常收工也记实况、推手机 程序已做；桌面上补一轮的效果待实测
压缩前后、子代理起止 Antigravity 没有对应事件 缺口，见下文

浏览器

  • 只读公开搜索用自带的搜索和网页读取。
  • 不用登录的日常网页（查、读、点、填不登录的表）可以用自带浏览器和它的 browser 子代理（本人 2026-11-18 同意）。
  • 要登录、要用本人 Chrome 或本人账号、要截本人 Chrome 的，默认经包装器派 Sol 操作本人 Chrome，型号和档位按模型清单「操作电脑和浏览器、截图」一行。GPT 有未到期的额度拒绝记录，或当前任务收到 GPT 的结构化 usageLimitExceeded 且能安全重派时，包装器才走 Antigravity CLI 的 /browser 接本人当前 Chrome；首次许可及连不上的交接见 browser-control-continuity 技能。

生图

画面照 image-generation 技能写好提示，默认经包装器交 GPT 生图。GPT 有未到期的额度拒绝记录，或本单在生成前收到 GPT 的结构化 usageLimitExceeded 且能安全重派时，包装器才交 Antigravity 自带生图；一张图一单，产物接入 generation.json 并注明来源，触发条件见模型清单「凡是看得见的」一行。

临时目录

任务临时文件放 E:\Cache\Antigravity\Temp\<对话号前 8 位>，子代理用自己的子目录（例如 <会话目录>\sub-<名字>），运行中只清理自己建的；会话和子任务的临时目录按规则表由自动清理处理。

技能、MCP 和记忆

  • 技能：插件 personal-env 的技能清单接 E:\.agents\skills，和另两家同一份，不另建副本；新技能写到 E:\.agents\skills 后走现有安装器。
  • MCP：Google 业务按能力与运行方式，走 PCConfig 的 google-workspace 本地入口。
  • 记忆：Antigravity 有没有自动记忆、怎么关，还没核实；需要留下的内容按共享经验的落点写进规则或项目文件，不写进它自己的记忆区，Antigravity 工具的已核实教训归本专题。

提问、收尾和另开对话

  • 要本人选的当场用 ask_question 给选项（大工程不弹选项，题挂到那一页，禁令见 design-with-owner 技能“怎么问”）。这一轮结束时还在等本人回话或动手，在最后一条回复的最后一行写“【等你】<一句人话>”（同 Codex），没有等本人的事就不写。
  • Antigravity 桌面根对话用 antigravity:<完整对话号>，和 Claude、Codex 共用同一套实况事项和手机通知，什么时候响、什么时候登记、答了怎么撤照 cockpit 技能。要本人知道、做或选的事照能力与运行方式由 AI 判断后登记实况。
  • 发现项目整体有毛病时，在当前对话下另派一个独立任务去完善，交代照分工与并行施工，施工照模型清单经共用包装器派 Sol，疑难按派 Astra 的禁令处理；Antigravity 能不能由 AI 自己另开顶层对话还没核实，核实前不另开。

额度和 AI 点数

  • 三家订阅额度各自独立，不互相比贵贱。Antigravity 的 Gemini 模型共用一份额度，Claude 和 GPT 模型共用另一份。两份各有周限额和 5 小时限额。一个池子用完，只算这个池子里的型号用不了，照模型清单那一行“这家用不了交谁”换人接着做，告诉本人；恢复后新活回原来的分工。AI 不查剩余量，包装器只记实际被拒，见派发说明。
  • 设置里“额度用完自动扣 AI 点数”（useAiCredits）已经关掉（本人 2026-11-18 18:08），基础额度用完不会自动花已买的点数。

官方升级

不以版本号当门槛：桌面运行版本、外壳文件版本和 agy 命令行版本本来就对不上（2026-11-18 分别是 2.32.2、2.31.0、1.5.11）。正常更新后入口、插件和钩子照常用；坏了按真实报错修，缺了某项宿主信息只让依赖它的那项变成不明或不可用，普通工作照常。

缺口

每项写缺什么、影响什么；接通或核实后改掉这一项。

  • 钩子：开场核对活动版、每轮北京时间、各次模型调用前取资料状态、生图拦截和登录网页提醒照常；未安装前资料状态按不明办。这些状态提示不授予权限。桌面对话里的显式用户输入有客户端消息编号时才入本人原话档；同号只存一次，钩子注入和命令行会话排除。符合这一来源的消息可以按发布规则提供批准。
  • 没有压缩前后、子代理起止事件：压缩会在对话里留下一步摘要（本机对话库里的步骤类型 23），叫模型前见到新摘要、里面没有工程和《他要什么》的位置才补；派帮手时的开场几行由动工具前那道钩子补；子代理登记和结束兜底仍靠长任务记录和包装器回执。
  • 原生子代理的类别对应哪款型号、名额上限：等额度恢复本机核对（档位能指定，本人 2026-11-19 说测过），影响本家能不能照清单派 Neon、Hydrogen。
  • 自动记忆、压缩后规则是否原样还在：待实测或核实。
  • 实况、思考摘要标记与打开对话：实况“AI 对话”已显示 Antigravity 原生提问和轮末提问的待答状态，答复后更新。思考摘要的“能／不能”标记已按完整对话号生效。从实况点“打开对话”可在主驾驶打开已登记的原对话。手机提问通知未接直跳原对话。
  • 自动任务的结论回执：现有回执入口只支持 Claude 和 Codex。Antigravity 的自动任务结论还没有接入实况“自动任务”；长期按时跑或以后某天要做的事，照 cockpit 技能登记成实况“自动任务”或“AI 约好的事”。
  • 最高权限：没登记，见上文“身份”。
