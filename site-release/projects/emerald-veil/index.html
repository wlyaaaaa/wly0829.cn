用途与结果

最快了解这个项目

为什么需要它

桌面图片不应随着项目目录搬家而丢失，换电脑也不该重新找图、调参数。空闲画面则需要在回来操作时及时退开，不能借屏保把远程桌面锁住，或让旧泡泡进程越积越多。这个项目分别处理图片恢复、空闲触发、窗口共存与停用恢复。

举个实际例子

“沿用我选好的壁纸，离开电脑一会儿让实体屏出泡泡；主屏关着就别往副屏上跑。”静态恢复和空闲程序独立工作。也可以按Ctrl+Win+E立即显示，松键稳定后才建立退出基线，正常移动或打字就回到工作。

最后我会得到什么

得到可恢复的静态图片设置，以及能查看状态、直接启动、预览、停用或卸载的原生泡泡入口。主屏不在时保持待命，不改变虚拟屏和仪表屏；没有实际看见画面时，不把进程或配置通过说成视觉验收完成。

正常工作

图片文件、固定图片模式和Windows回读一致时，恢复脚本报告完成。泡泡程序正常运行并达到六分钟可靠空闲时才显示；普通活动会把画面收起。

发现问题

配置发生漂移或常驻程序停止时，先分开核对设置、安装与进程，再处理相应问题；静态图片不因此被重新生成或替换。本轮已经修正超时值并恢复现有程序。

暂不可用

系统缺少Bubbles.scr、没有可用的当前用户桌面或已有另一原生泡泡实例时，不再启动一份。缺少选图或图像校验不符时，静态恢复入口直接报错。

从哪里开始

先运行 scripts/Set-WindowsBackground.ps1 -Action Verify/Apply 检查或恢复图片；泡泡另用 scripts/Install-EmeraldVeil.ps1 -Action Install 和 scripts/Set-NativeBubbles.ps1 -Action Enable。

需要准备什么

  • 想用的项目图片
  • 桌面、锁屏或泡泡的选择
  • 要启用还是恢复原设置

它负责

  • 保存并恢复已选Windows桌面/锁屏静帧与换机入口。
  • 六分钟可靠空闲或明确启动时显示原生泡泡，正常输入收起，实体屏缺席待命。
  • 让专属背景、原生泡泡、已有Wallpaper Engine和外部黑罩按各自职责共存。
  • 保存受影响设置的原状态，明确停用、还原、卸载和实际验证的区别。

它不负责

  • 不提供安全锁屏，也不改变用户主动锁定电脑的选择。
  • 不重新分发Windows的Bubbles.scr或微软泡泡素材。
  • 不添加网络、遥测、持久活动日志、屏幕截图或第二个输入监控系统。
  • 不接管Wallpaper Engine选图、播放列表或持久配置。
  • 已拒绝的猫分层草稿不属于现役功能，不作为待办自动恢复。

产品思想与设计核心

01

壁纸恢复和空闲画面各做一件事

静态图片只需原脚本、选图与文件即可恢复，不必安装泡泡。泡泡另按VDD当前Wallpaper Engine材料或Windows壁纸选择背景，只显示被确认的实体桌面屏，身份不足就待命。

02

泡泡借用系统原件，操作还给用户

保留Windows原生泡泡的材质与运动，不重画一套。覆盖层不抢焦点、不主动锁屏，正常输入时退开；远端是否好用仍要看实际客户端。

03

区分真操作和没有意义的鼠标消息

有些设备或远程工具会发出指针根本没动的消息，不能让它们不断重置空闲时间；连续移动、按键和滚轮仍算活动。判断事件本身，不按软件名称猜用户在不在。

04

已有画面和保护工具可以继续用

设置静态图片时不改Wallpaper Engine。启动泡泡时只短暂协调其当前会话播放；外部黑罩持有暂停标记时，泡泡连预览也会让位，标记消失后恢复原来的策略。

05

停用、还原和卸载说清楚

Disable先停止泡泡和自动触发；Restore还原第一次启用前保存的屏保参数；Remove移除项目自启和程序。原壁纸在Windows设置里按保存记录选回，不冒充一个命令能还原电脑所有改动。

当前缺口

  • 驻留进程是Ctrl+Win+E唯一Owner，现不提供“暂停本次会话”或托盘退出驻留入口；可以通过正式Disable/Restore/Remove管理功能。Windows应用重启登记不等于已实测每种崩溃/自然开机，未新增服务、任务或第二守护器。
  • 桌面/锁屏接口回读通过，不等于本轮看过真正锁屏画面；跨机器设置流程已有实现，本轮未在第二台电脑重新应用。
  • 原生泡泡的大小、数量和边缘运动由Windows实现决定；当前版本采用未公开的Radius参数，系统更新后需要重新确认实际画面。
  • 泡泡让静止画面多一些运动，不保证OLED不会烧屏；亮度、面板维护和自动息屏仍由显示器及系统负责。
  • 远程兼容依靠同一用户桌面、输入穿透和不主动锁屏；不承诺所有远程软件、网络和显示器组合已经实测。

完整执行流程

  1. 1
    先恢复喜欢的图片

    从选图清单找到已保存PNG，按需保存原始记录、复制到本用户持久目录并设置Windows桌面和锁屏，最后读取实际结果。

  2. 2
    需要泡泡时再安装启用

    安装单个程序与直接登录启动项，然后用Enable配置六分钟策略；不把一次性图片恢复变成长驻服务。

  3. 3
    等待可靠空闲

    程序每50ms观察输入；无意义鼠标移动不重置计时，暂停、外部黑罩或不可靠读数会阻止自动显示。

  4. 4
    显示并维护两层画面

    和现有壁纸播放做短暂协调，显示专属背景，再启动原生泡泡；维护两层位置，输入或停止操作到来就收起。

  5. 5
    问题按层处理

    仍空闲时可重试意外退出的渲染器；静态背景漂移按需重跑Apply（应用图片）；想撤回时分别处理屏保参数、程序安装和原壁纸。

需要核对专业含义时，可以在这里查看它在 Emerald Veil 项目中的具体用法。

Bubbles.scr
Windows自带的气泡屏幕保护程序。本项目使用系统现有副本的/s全尺寸模式，微软仍决定泡泡材质、运动和数量。
watchdog（看门狗）
这里指本用户会话中的小程序：等待空闲、显示泡泡、响应活动、重试意外退出的渲染器。它不是系统服务。
Job Object（作业对象）
把本次启动的泡泡进程交给Windows统一管理；关闭最后一个作业句柄时结束其子进程，减少退出后残留。
Color-key（色键透明）
把原生泡泡窗口中的黑色像素设为透明，让下面的项目背景显示出来。背景窗口本身仍是不透明图片。
Preimage（变更前状态）
修改前保存的具体原状态，用于按原样恢复；它不代表备份整台电脑，也不自动证明所有操作完全可回滚。
DWM（桌面窗口合成器）
Windows负责组合各个窗口画面的组件。这里等待其完成一轮合成，避免泡泡初始化时使用尚未稳定的背景。
GetLastInputInfo
Windows提供的最近输入时间。项目结合少量内存中的事件分类计算空闲，不保存用户按键、活动日志或截图。

系统里实际有什么

下面是当前产品组件，不是概念分类。每一项都对应真实文件、入口或验证链。

01
Set-WindowsBackground.ps1

恢复Windows桌面与系统锁屏图片

读取选图清单和PNG，核对SHA-256，通过IDesktopWallpaper与Windows.System.UserProfile.LockScreen设置并回读。PowerShell 7自动转到Windows自带64位Windows PowerShell运行WinRT接口。

02
EmeraldVeil.App

在当前用户桌面等待空闲，显示与收起泡泡

.NET Windows WinExe承载原生泡泡与所选VDD背景快照，托盘显示目标、空闲时间和最近失败，并提供立即启动；双击和Ctrl+Win+E进入真正屏保，preview仍限15秒。原Run项保持用户会话运行，Windows Application Restart负责受支持的异常恢复。

03
EmeraldVeil.Core

区分可靠空闲、活动、启用状态和外部保护让位

IdleTimeline处理计时、回绕与不可靠采样；InputActivityFilter只在内存判断活动；VeilActivationPolicy和VeilModeReconciler决定显示/隐藏及1秒恢复退避。

04
NativeBubblesLauncher / VeilWindow

管理原生泡泡进程和两层画面

会话租约防止重复启动，Job Object（作业对象）关闭时结束子进程。原生泡泡窗口使用黑色色键透明；不透明的项目背景窗口紧贴其下，两者都不接管用户输入。

05
WallpaperEngineQuiescence / ExternalProtectionPause

和已有壁纸、外部黑罩协调

唯一识别当前会话wallpaper64，再用同目录wallpaper32控制stop/play；外部暂停只看会话内命名标记是否仍被持有，不识别远程产品或记录输入。

06
Set-NativeBubbles.ps1 / Install-EmeraldVeil.ps1

配置、检查、停用、恢复和安装

原屏保参数保存在本机前像；安装器部署单个程序并注册直接WinExe Run值，不建立服务、计划任务或额外常驻脚本。

当前数据合同与写读边界

01
assets/windows-background.json

name / image / sha256 / width / height / color / renderSettings

静态背景脚本：选图SHA-256 FA8D1FDC7799D537864D2784B5718E8BA15B77775D246C019179084B0F0239E7；3840×2160。参数vivid=0.5、rain=0.75、wind=0、haze=0.5、depth=0、rainStyle=1，只记录选定画面来源，不让Windows运行动态雨幕。

02
%LOCALAPPDATA%\EmeraldVeil\windows-background\before-first-apply.json

capturedUtc / desktopPath / desktopBackup / wallpaperStyle / tileWallpaper / lockScreenOriginalUri / lockScreenBackup / pictureSelectors

静态背景脚本：这是脚本保存的JSON记录，没有另一个wly.*版本schema（数据结构）。首次保存原图和模式，重复应用不覆盖原图；缺少旧selector字段时只补采该字段。原图片按记录在Windows设置里选回。

03
%LOCALAPPDATA%\EmeraldVeil\native-bubbles-preimage.json

emerald-veil.native-bubbles-preimage.v2；兼容v1

Set-NativeBubbles.ps1：保存runtime（运行环境）和registry_values，逐项含路径、名称、存在性、类型、值；v2包括NativeBubblesEnabled，v1恢复时将该标志还原为不存在。记录留在本机。

04
原生泡泡配置

HKCU Desktop + Screensavers\Bubbles + Software\EmeraldVeil

配置脚本与常驻程序：SCRNSAVE.EXE指向系统Bubbles.scr；ScreenSaveTimeOut=360、ScreenSaveActive=0、ScreenSaverIsSecure=0均为REG_SZ；Radius=1130000000、NativeBubblesEnabled=1为REG_DWORD。常驻程序每30秒修正运行时策略，不是全注册表定时重写器。

05
会话内进程与窗口

native-bubbles-session-<session>.lock / JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE / HWND

NativeBubblesLauncher：租约和当前会话进程检查拒绝重复实例，不接管已有原生泡泡。启动进程归作业对象，退出时先隐藏已持有窗口，再释放进程和租约。

06
Local\EmeraldVeil.ExternalProtectionPause

会话内命名mutex（互斥体）的句柄生命周期标记

外部保护程序创建，Emerald Veil只读观察：以initiallyOwned=false创建，持有句柄即让位；无需Wait或ReleaseMutex。观察者立即关闭探测句柄，最后持有者关闭或崩溃后标记消失。

维护入口

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Set-WindowsBackground.ps1 -Action Apply

恢复桌面与锁屏图片：在项目目录运行；使用已保存图片，不重新生成。会修改当前用户个性化设置，先保存原始图片与设置记录。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Set-WindowsBackground.ps1 -Action Verify

只检查图片：核对图片、固定模式、持久路径和解码锁屏画面，正确返回verified/0，漂移返回drift/1；不锁定会话。

dotnet publish .\src\EmeraldVeil.App\EmeraldVeil.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\artifacts\publish\win-x64

构建可安装泡泡程序：从源码安装需.NET 10 SDK；生成安装器默认读取的单文件程序。不因构建自动启动泡泡。

pwsh -NoProfile -File .\scripts\Install-EmeraldVeil.ps1 -Action Install

安装或更新泡泡程序：部署到本用户Programs\EmeraldVeil，注册直接启动项并启动程序；Enable不是安装器，不能替代这一步。

pwsh -NoProfile -File .\scripts\Set-NativeBubbles.ps1 -Action Enable

启用六分钟自动泡泡：保存第一次启用前的原状态，写入360秒、半径和enabled标志，并关闭Windows自己的自动屏保触发。

pwsh -NoProfile -File .\scripts\Set-NativeBubbles.ps1 -Action Verify

检查泡泡配置：检查屏保注册表与运行时；程序是否运行和实际画面仍需分别观察。

pwsh -NoProfile -File .\scripts\Install-EmeraldVeil.ps1 -Action Verify

检查程序安装：检查已安装的程序与自启项，不把安装一致当作实屏效果已通过。

pwsh -NoProfile -File .\scripts\Set-NativeBubbles.ps1 -Action Disable

立即停用泡泡：停止匹配Windows系统路径的泡泡进程，清除项目enabled标志，并让Windows自动触发保持关闭。不是只读操作，也不会还原静态壁纸。

pwsh -NoProfile -File .\scripts\Set-NativeBubbles.ps1 -Action Restore

还原原屏保设置：还原第一次Enable前记录的精确键值存在性、类型、值和运行时状态；不是恢复Windows默认值，也不是卸载程序。

pwsh -NoProfile -File .\scripts\Install-EmeraldVeil.ps1 -Action Remove

卸载泡泡程序：移除项目自启项和已装程序。若同时要回到原屏保设置，先按Restore处理；恢复记录留在本机。
