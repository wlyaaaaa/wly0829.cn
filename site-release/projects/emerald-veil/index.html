它是怎么搭的 1 登录就启动 Windows 开机项直接打开一个常驻程序：C# 写的，.NET 10，打包成一个约 173 MB 的单文件；托盘里一个绿图标。没有服务，也没有计划任务。 2 盯着有没有人 每 50 毫秒读一次 Windows 记的“最后一次输入时间”；键盘鼠标钩子只在内存里判断假动作，不记内容。 3 满 6 分钟 按硬件身份挑出主屏；主屏关着、盖着黑幕，就不放。 4 先铺底图 把虚拟屏上 Wallpaper Engine 选的那张铺到主屏，没有就用 Windows 壁纸；这一层鼠标点得穿。 5 放泡泡 启动 （本机路径） /s，按物理像素摆到主屏最上层、不抢焦点。泡泡启动时对底图拍一次快照，所以泡泡底下是静止的一帧，不是还在动的动态壁纸。 6 一动就收 先撤底图，再关泡泡。泡泡进程挂在“程序一关就跟着关”的 Windows 作业对象里，常驻程序退出或崩溃都不会留下泡泡。 壁纸工具：一个 PowerShell 脚本，用 Windows 的桌面壁纸接口（IDesktopWallpaper）和锁屏接口设置，再逐块屏回读；不装开机项、服务或定时任务。 规模（9 月 29 日数）：C# 3,266 行 · PowerShell 1,556 行 · 67 个自动测试 · 45 次提交（8 月 11 日–9 月 29 日）· 现在装的是 0.1.39 版，从源码装，不发安装包。每次推送到 GitHub 自动构建、跑测试，最近 5 次都通过。
为什么这样设计 1 到点由它自己放，Windows 设置里的屏保开关一直关着。 Windows 自己的屏保会铺满所有屏，还可能黑屏、锁屏；由它计时，只在主屏放泡泡，远程连着也不会被锁在外面，两个屏保也不会抢。 2 虚拟屏宁可不放。 原版泡泡在这台电脑的虚拟屏上画不稳。自己画泡泡、给系统文件打补丁、重置显卡驱动都能“修”，都被否了。 3 只看有没有动，不记按了什么。 键盘鼠标钩子只在内存里留上一个鼠标位置；不记按键内容、不记坐标轨迹、不写活动日志，也不列远程软件的名单。 4 一个程序、一个开机项。 没有服务、没有计划任务、没有第二个守护程序；崩溃或卡死后，Windows 自带的“应用重启”会提示重新打开，我点确认才开。托盘里故意没有“退出”：Ctrl+Win+E 靠这个程序接，随手退掉等于悄悄废了快捷键。 5 失败不会死循环。 泡泡没起来，隔 5 秒、再隔 30 秒重试，第 3 次失败这次闲着就不再试；正常放满 30 秒，失败次数清零。 6 拿不准就不放。 屏幕认不出身份、输入读不准、主屏盖着黑幕，一律按“不放”处理；屏保停用时，托盘和快捷键也叫不出泡泡。 7 停用就是真停，不会关了又冒出来。 先把它自己的开关和 Windows 设置里的屏保开关都关掉、挡住下一次启动，再收起这个登录会话里的泡泡；收画面失败，也不会把开关改回“开着”。要停就跟 AI 说“把屏保停了”。
泡泡出来两秒就没了，查到是远程软件的“假动作”。 8 月 13–14 日抓到一次：泡泡出现约 2 秒就自己没了，那一刻没人碰键盘鼠标，只有远程软件发来的一次鼠标挪动；它还会发一种“原地不动”的鼠标事件。中途 AI 把另一次消失也算在远程软件头上，本人指出那次是自己在测试，这个结论就作废了。最后的规则很窄：纹丝不动的移动不算；单独一次小挪动先不算，250 毫秒内再来一次才算有人在远程动鼠标；真动鼠标、点击、滚轮、按键，照样一碰就收。 泡泡是 Windows 原版的，一个都没自己画。 本人要的是“像 Windows XP 那样的泡泡屏保”，还“看着不能太丑”。自己画要重做玻璃质感和碰撞，还很难一样好看。它直接启动 Windows 里现成的泡泡屏保：颜色、玻璃、碰撞都是微软原版，项目只管什么时候放、放哪块屏、底下垫什么。有个坑：把泡泡窗口里的黑色抠成透明，半透明的玻璃边会变成一圈圈黑环，所以整块窗口原样摆上去。
