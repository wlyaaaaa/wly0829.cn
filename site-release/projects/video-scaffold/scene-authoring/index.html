video-scaffold · 功能说明

把旁白、真实素材和动画规则收进可审阅的 SVG 场景

工具把旁白、实际读到的重点词和本期素材整理成逐场提示；人或 AI 只制作可审阅的画面片段，公共动画模板负责让它动起来。

用途与实际影响

这项功能怎样使用

为什么需要它

让 AI 一口气生成整个播放页面，容易重复公共动画、跑错时间或引用根本不存在的素材。只做每场小画面，既方便人审阅，也让公共播放规则只维护一份；缺项能在构建时定位。

举个实际例子

我可以说：“第二场只用我给的 hero.png；念到‘三项变化’时画三条线，最后数字滚动到 82。”系统会把真实素材和说词时间交给场景制作，只有审阅通过的画面才进入预览。

最后我会得到什么

得到每场的提示、画面片段和可预览页面。工具检查场次、重点词和动画规则；具体画面是否准确、好看仍由人审阅。

正常时

逐场画面已经审阅，编号和重点词能对应当前旁白；结构检查通过后进入预览。

发现问题时

词重复、识别错或素材含糊时回到旁白与原图确认，不凭猜测把画面贴上去。

入口不可用或证据不足时

缺场景脚本、时间位置或画面片段就停止；明确无需素材的场景仍可制作。

从哪里开始

在旁白和词轴就绪后运行 run.ps1 prompts，按提示把每场可审阅的 SVG 片段保存为 fragment_NN.svg。

需要准备什么

  • 每场要表达的内容与画面要求
  • 真实素材或明确无素材
  • 需要对齐的重点词

从开始到拿到结果

  1. 1

    工具整理本场提示

    把旁白、实际读到的重点词和本人提供的素材放在一起；没有素材的场也明确标出。

  2. 2

    人或 AI 制作画面片段

    只保存这一场可审阅的画面，核对事实、布局和动画，不生成另一套不受控的整页程序。

  3. 3

    构建前对齐编号

    画面文件要与本场旁白对应；工具发现缺场或重点词对不上就停止。

技术实现与依据

这里保留实现、关键条件、精确入口、历史记录和验证结果。

通用场景合同与组件已实现；本轮无新场景或作品

关键规则与设计选择

1

prompts 不是自动场景生成，保存 fragment 才是创作动作。

2

cue 必须来自真实发音，屏幕数字与旁白读法不一致时选择稳定邻近词。

3

高级动效仍必须是时间 t 的纯函数，不能因预览能动就引入真实时钟。

本模块用到的名词

fragment（场景片段）
只放在公共 SVG 舞台内部的本场内容，不重复整页运行时。
data-anim（动画原语）
声明元素随时间如何出现、移动或变化；实际状态由 seekTime(t) 计算。
file URI（本地文件地址）
把明确素材的绝对路径编码给浏览器使用；没有素材就明确写无，不虚构。

专业定义

提示词只准备证据；真正的 SVG 片段必须由人或 AI 审阅。

解决什么

防止模型生成失控页面、素材引用凭空出现，以及动画表面正常却与旁白没有可追溯关系。

当前怎样实现

  • author.py 读取脚本和 srt，注入实际可用词串与素材 Path.as_uri()，没有素材时明确写无；它只生成 prompt_NN.txt。
  • 片段不重复 html/style/script 或独立时钟，定位放外层、动画放内层；构建验证重复属性、已知动画、合法时间和 cue，内容布局与审美仍由人或 AI 审阅。
  • build_scene.py 支持正常单/双引号属性、有限中文数字变体、data-cue-index 和 data-cue-offset；解析后仅有一个生效延时，未命中或非法属性明确失败。
  • scene_base.html 的 seekTime(t) 实现 type、fade、draw、count、grow、wipe、move-along 等原语。
  • v2lib.py 和 components.py 提供标题、数字、表格、路径、全息、形变、粒子、流体、翻转、脉冲等静态片段生成器；随机参数在 Python 端固定。

执行流程

  1. 1

    脚本与时间轴就绪后运行 prompts。

  2. 2

    阅读本场旁白、可 cue 词与真实素材 URI；无素材场景可以继续。

  3. 3

    人或 AI 设计 SVG 片段并按结构指南审阅。

  4. 4

    按规范命名 fragment_NN.svg。

  5. 5

    build 强制脚本、时间轴与片段编号一致，解析 cue 并组合公共模板；已引用素材的存在性在渲染身份阶段检查。

边界

  • 组件库提供画面能力，不替人判断事实、审美和信息层级。
  • 重复 cue 已可选择具体次数；词轴估计或词内插值的误差仍需听音与有声预览修正。
  • 旧定制 builder 和封面只留 Git 历史，不是当前活动入口；原工程文件不因升级被自动删除。

失败与恢复

片段包含指南禁止的结构
重复属性、未知动画和非法时间由构建阻断，其它内容与视觉问题由人或 AI 退回修改；不把合同通过说成完整美学验收。
cue 未在时间轴找到
明确阻断 build/verify；先核对音频与词轴，选择真实词语、出现次数或偏移，再重建和听看。
已引用的素材路径不存在
提示阶段不虚构，渲染身份读取 资源时会直接失败；没有引用素材的场景不因此失败。
