AI CLI（命令行工具） Profile Manager

用途与结果

最快了解这个项目

为什么需要它

同一台电脑上同时用官方登录、第三方模型服务（API）和本地模型时，最容易发生的事故不是命令记不住，而是旧环境变量把请求送错地方、同名模型实际换了版本、失败后悄悄走了别的线路，或只因命令行界面（CLI）能打开就误判任务可用。aicli 把每次选择写成可检查的运行计划，让秘密只进入目标进程，再把静态检查、真实调用和任务结果分开报告。

举个实际例子

“这个项目先用我选好的本地模型，在原来的 Codex 桌面继续；需要请 OpenAI 帮忙时单独说清。”我看到的仍是熟悉的工作台。系统先核对当前安装支持的配置；额外协作保持独立模型身份和原会话，不把选择本地模型当成默认同意外发。

最后我会得到什么

我得到原生 CLI（命令行工具）、桌面任务或带编号的程序化运行；需要后台协作时，还能让同一个子会话持续回答、报告进展或回来提问。诊断先给缺项和实际入口；取消必须确认对应进程与显卡租约已经释放，不能只把“已收到停止请求”说成结束。

正常时

选定的配置档确实启动了指定程序与模型；若另做了真实调用，还会说明回答、工具和任务结果。

发现问题时

设置冲突、模型已换、代理没运行或本地服务不可用时，只标明这条路线的问题，不悄悄换另一个模型。

入口不可用或证据不足时

配置档损坏、需要的凭据缺失或原任务身份无法确认时，停止相应启动或恢复，并说明怎样修复。

从哪里开始

这是在电脑上选择模型并启动已有 AI 编程工具的管理器：打开 Windows PowerShell，用 aicli profile list/show 查看配置档、aicli native 预览、aicli start 启动。Codex 桌面本地模型与子任务仍在官方 Codex 界面使用。

  • 想用的 CLI（命令行工具）、模型及数据去向
  • 第三方服务是否已有凭据和是否愿意做真实调用

它负责

  • 保存可选择的 AI 编程工具与模型配置档，并在启动前展示程序、服务和数据去向。
  • 从已核对的 OpenClaw 设置导入指定 DeepSeek Flash 配置时先预览，再由本人明确应用。
  • 启动现有 Codex、Claude Code、Qwen Code、OpenCode 和受支持的 Open Interpreter；本地模型也可接入已有 Codex 桌面。
  • 只把第三方服务所需的密钥交给目标程序，避免污染其他终端或官方登录。
  • 先做不发模型请求的体检，需要时再明确执行文本、工具或真实文件任务测试。
  • 为程序化工作留下可查询的任务编号；中断先查原任务，获准的桌面父任务可与同一个后台子会话往返。
  • 管理可选代理的安装、登录和退出，并说明哪些状态只证明安装、哪些证明真实可用。
  • 提供可回退的安装、更新与卸载，并写清保留或清除哪些用户配置。

它不负责

  • 它启动已有 AI 工具，不另造聊天窗口或统一聊天历史库。
  • 不会修改上游工具本体，也不会把一个工具的模型、权限或命令硬套给另一个。
  • 模型、账号或服务失败时不自动转到另一条可能收费或外发资料的路线。
  • 网站说明更新不触发付费模型调用、登录、代理启动或显卡模型下载。
  • 配置存在、静态体检通过或旧回执都不等于每个模型现在可用；删除本机登录文件也不会撤销远端授权。

产品思想与设计核心

01

仍用原来的 AI 工作台

配置档只帮我选程序、模型和数据去向；终端交互继续由原生工具负责，桌面工作继续用官方 Codex 的界面、工具和历史。后台协作保留同一真实子会话。

02

每次工作都知道用的是谁

同名模型可能属于不同服务或付费线路。启动前显示准确版本、服务、地域与思考档位；发现被改送别处就停下，不当作方便的自动备用。

03

密码只给这次需要的程序

配置档只保存受保护的密钥引用，真实密钥在本机加密保存、启动时交给目标程序；父终端、聊天、日志和导出说明不显示明文。官方登录与第三方服务各走自己的认证。

04

能打开程序和完成任务分开证明

安装、静态体检、模型回答、调用工具和实际文件结果各有自己的结论。型号或连接方式改变时重新核对相关证据，单纯版本号变化不让全部工作永久停摆。

05

中断先接原任务，不复制一份假续作

继续前核对原会话、工作目录、模型和权限；目标或身份变化时明确重新开始可能重做动作，不把复述摘要说成断点恢复。

06

启动前能预览，离开时也带得走

可查看不会泄露密钥的启动计划，也能导出独立使用的配置说明。普通卸载保留用户数据，明确彻底清理才删除本工具保存的内容。

07

一条路线故障只报这一条

本地模型、云端服务和代理分别判断。缺登录、服务离线或证据过期时说明该怎么修，不自动改用别的账号、模型或资料去向。

我给它什么，它实际把什么交给谁

这款工具只使用本次选定的项目目录、模型配置与必要登录材料，不读取统一的私人资料库。下面说明每类输入交给哪个程序、我会看到什么。

01
我正在工作的项目目录

本次打开的文件夹或明确指定的项目；额外参数逐项交给选定工具。

原来的 AI 编程工具从该项目开始工作，实际读写仍受它的权限和这次任务控制。

02
选定的模型配置档

记录要启动哪个程序、哪个模型、服务地点与受保护的凭据引用，不保存明文密码。

启动前可读脱敏计划，确认材料会去哪里。

03
可选的 OpenClaw 设置

只读取本人点名的现有设置并核对来源；默认先预览，不自动导入或接受未知服务地址。

明确应用时只导入对应 DeepSeek Flash 配置，密钥转入本机受保护保存。

04
第三方密钥与官方登录

第三方密钥在当前 Windows 用户下加密保存，启动时只交给选中的目标程序；官方工具沿用其自己的登录。

其他终端和工具不会被永久改到第三方服务，普通输出也不显示密钥。

05
静态体检与明确选择的真实测试

静态体检只看程序、配置和服务状态；真实测试才发一次模型请求或做一项小文件任务。

分别拿到设置缺项、模型回答、工具结果或实际文件结果；一层通过不顶替下一层。

06
后台任务的公开进度

只记录任务编号、可公开的进度、结果和停止状态，任务正文不写进恢复记录。

可以查询、继续或精确停止原任务；隐藏推理和工具原文不会作为历史散出。

07
本地模型与可选代理

选中的本机模型或代理各查自身是否真在运行和是否属于批准版本。

身份对得上才标这条路线可试用，未运行或端口不对时报告原因。

配置之间的隔离只防止模型服务与密钥意外串线，不承诺程序只能读当前文件夹；让编程工具处理文件前仍要确认任务和工作目录。

完整执行流程

  1. 1
    先确认本次工作目录

    在可信项目根运行，或用 --project 指定路径；它决定原生 CLI（命令行工具） 能看到和工作的上下文，不是 AI 的统一记忆库。

  2. 2
    查看并选择一个明确 Profile

    用 profile list/show 核对引擎、模型、数据去向、是否需要秘密和当前状态；第三方云路线按需无回显配置 Key。

  3. 3
    在启动前查看脱敏计划

    native 展示可执行文件、参数、环境增删和目标服务。若 Provider、模型或官方登录可能被劫持，先在这里与 Doctor 定位。

  4. 4
    启动原生 CLI（命令行工具） 或程序化 run

    CLI（命令行工具）交互用start，程序化工作用run start；桌面选择已登记模型。CLI（命令行工具）切换Profile创建新进程，桌面同一Provider内可切模型；官方、第三方、本地这些不同Provider之间另开任务，不重写原会话身份。

  5. 5
    先做免费静态体检

    Doctor 核对依赖、Profile、秘密引用、配置层、代理、本地服务和旧证据；它不会擅自发一条模型请求。

  6. 6
    只有确需时再做真实验收

    明确选择 text、tool 或 agent，并阅读可能耗额度和产生工具副作用的提示；结果绑定实际 CLI（命令行工具）、模型、Provider、权限与 Profile 指纹。

  7. 7
    问题按原路线修，退出时保留边界

    按 check ID 修当前入口，重新开进程后生效。native/eject 帮助脱离工具；卸载先区分保留数据、彻底清理和远程 OAuth（账号授权协议） 撤销。

本页用到的名词

需要核对专业含义时，可以在这里查看它在 AI CLI Profile Manager 项目中的具体用法。

Profile（运行配置档）
一次明确的引擎、Provider、模型、地域、项目偏好和秘密引用组合；启动前可以查看，改变后只影响新进程。
Provider（模型服务接入定义）
模型请求实际发往的服务和协议；同一模型名在不同 Provider 下不是同一个运行身份。
SecretRef（秘密引用）
用户 Profile 保存的不透明引用；真正 Key 由 DPAPI 密文持有，只在目标进程启动时短暂注入。
Doctor（静态体检）
读取本机版本、配置、端点和服务状态，但不要求模型生成内容，也不证明付费线路已通过。
Live Test（真实能力测试）
通过目标 CLI 发真实请求；text、tool 与 agent 分别验证正文、单用途工具和非平凡文件任务。
machine run（程序化机器运行）
供上层程序用 stdin/JSON 发起任务的入口；Codex 路线可后台查询、精确恢复和协作中止。
exact resume（精确恢复）
继续原来的同一 thread/session，并回验工作区、Profile、模型、Provider、effort、CLI 与权限，而不是新建对话后重述。
no-fallback（不自动回退）
当前入口失败时保留失败，不静默换模型、服务、账号或本地路线。
