接入方式与认证＋

需要支持远程 MCP 的客户端。不同工具的设置位置、认证方式和能力支持不同；地址本身不包含操作权限。

OAuth 登录授权
适用于当前已登记的客户端。首次连接时，按客户端提示完成授权。
Bearer 凭据
已有兼容方式，供支持此认证的客户端使用。凭据在私下配置，不会展示在网页上。
已验收的示例
ChatGPT 已完成真实工具调用验收。可在插件设置 添加或管理连接。其他客户端仍需各自完成接入验证。

如果新工具无法完成认证，应先确认它支持哪种方式，再配置对应授权。
