加密库操作 让 AI 帮我管本地加密库：检查 vault.enc 坏没坏，在本机窗口里打开看、改几行字，建新库、导出、改密码，把密文备份到私人 Key 仓库。要密码时，AI 只弹出本机窗口让我自己输；回到 AI 手里的只有“成没成、存在哪、几个文件、密文哈希”。 可以这样跟 AI 说： “看看 Key 那份加密库还好不好。” “打开 vault.enc，我要看里面的清单。” “把 vault.enc 里那份笔记的第二段改一下。” “把这个文件夹加密成一个新的 .enc 库。” “改一下 vault.enc 的密码。” “把改好的库备份到 Key，传完核对一下。” 只说“帮我加密这个文件”、没提 vault.enc、Key 或 VAULT03 时，默认交给加密文件技能，走密码中心那一套。
一个完整的例子：“把 vault.enc 里的清单改一句，改完备份到 Key” 1 先查，不要密码。 AI 查环境和这个库的结构：格式对不对、要不要密钥文件、Key 是不是私有仓库。有一项不对就停下来说清楚。 2 弹出本机窗口。 顶栏写着“VAULT”；我输密码，要密钥文件就在窗口里选。密码框一拿到光标就断开输入法。 3 在窗口里改。 窗口列出库里的文本文件，选中清单改那一句；不是文本的文件原样保留、不能改。 4 保存。 只重新加密这次打开的那一套内容，另一套一个字节都不动；改完必须装得进原来的空间，装不下就拒绝保存，原库不动。写完读回再解一遍核对。 5 先预演，再上传。 AI 先预演一遍往 Key 上传，确认目标是私有仓库、路径对；再真的上传，从 GitHub 读回比对长度和 SHA-256，两样都对才说“备份好了”。 回执里有：成没成、存没存、路径、密文哈希。 没有：密码、密钥文件、改了哪些字。
能做的事 这个技能是本地加密库的 AI 入口。它能做的，以及只能我自己在终端里做的（往已有的库里加文件用菜单，另做一份新副本用 rebuild 命令），全部列在项目页的“全部功能”里，这里不再抄一遍： 本地加密库 · 全部功能
边界 管 vault.enc 这类 VAULT03 库（旧的 VAULT01、02 也能读），和私人 Key 仓库 在本机窗口里查看、修改库里的 UTF-8 文本 建新库、导出到指定文件夹、改密码、验一次密码、藏进图片和从图片取回 把密文传到 Key 并读回核对；明确要求时，把 Key 的说明文件换成安全文字 不管，交给谁 没点名的“帮我加密这个文件” → 加密文件技能 密码、API key、BitLocker、本人验证方式 → 密码和验证技能 往已有的库里加文件、另做新副本 → 我自己在终端做：加文件用 python vault_tool.py 的菜单，新副本用 python vault_tool.py rebuild --out 新文件 忘了密码、丢了密钥文件 → 谁也找不回 守的几条死规矩 密码只在本机窗口里输，不进聊天、命令参数、环境变量和文件；只动点名的那一个库，不去别处找；只读检查不解密；导出只写到点名的文件夹，同名文件不覆盖；建库不删原件；改密码不改算钥匙的参数，另一套内容不碰；只往私有仓库上传，不定时自动传；验一次密码不留授权，下一个操作要再输。
