加密文件 把我点名的文件或文件夹，交给密码中心加密成一个 .pcaf 文件夹；以后核验、解开、查看、修改，按本人验证规则办（四选一；受信任的桌面 AI 可复用有效资料期或无限制授权）。不用另记密码，原件也不动。 可以这样跟 AI 说： “帮我加密这个文件夹。” “这个 .pcaf 还能恢复吗？” “把它解到 （本机路径）。” “打开里面的 notes.txt 给我看。” “把里面这段话改一下，另存一份。” 没说用哪一套时，“帮我加密这个文件”默认走这里；说的是 vault.enc 或 Key 仓库，就交给本地加密库那一套。
一个完整的例子：“帮我加密 （本机路径） 这个文件夹” 1 只认点名的路径。 AI 只处理这一个文件夹，不去扫下载、文档或整块盘；遇到符号链接、目录联接这类指向别处的链接直接拒绝。 2 验证一次。 受信任的桌面 AI 复用有效资料期或无限制授权；否则让我四选一验证。 3 加密。 没说放哪，就放在 （本机路径） 下面新建的 .pcaf 文件夹里；原件原地不动。怎么加密见密码中心 · 钥匙一层套一层。 4 读回核对。 加密完再认一遍整个包，核对每个文件的哈希，才报“完成”。中途断了，下次核对已完成的部分再接着做。 5 跟着备份走。 这个文件夹随文档每天备份到 G、再到 H；G、H 各自确认，H 没接上就写“待定”。 回执里有：文件数、路径、哈希、状态。没有：文件内容、钥匙。
能做的事 这个技能是密码中心文件加密的入口：加密、核验、解开、查看、修改、中断续做、在新电脑上解开，全部列在密码中心的“全部功能”里，这里不再抄一遍： 密码中心 · 加密文件
边界 管 加密、核验、解开我点名的文件、文件夹或 ZIP 在本机窗口查看或修改包里的一个文本文件（只限 UTF-8 文本） 在一台没登记过的新电脑上，凭完整程序、恢复副本和 .pcaf 解开 不管，交给谁 密码、key、银行卡、磁盘恢复钥匙 → 密码和验证技能 用自己记的密码加密的 vault.enc → 本地加密库 不是文本的文件不在窗口里打开，要用就解到一个指定的文件夹 守的几条死规矩 只动点名的路径，不扫盘找文件；原件和加密包都保留，不自动删除、上传或挪走；解开时遇到同名文件不覆盖；文件内容和钥匙不进聊天、日志、剪贴板；修改一律另存新包，原包不动；钥匙和密码库、本地加密库都不共用。
