我自己看桌面

日常用 Moonlight 连主机（电脑上跑的是 Sunshine；Artemis 也能连）。副机也以 Moonlight 为主，网易 UU、ToDesk 备用。

怎么连
1
打开手机或笔记本上的 Moonlight，点已经配对好的主机。人不在家时，这台设备要在 Tailscale（只连我自己设备的私人网络）里。
2
看得见桌面、点得动，才算连上。
3
断开后看一眼：主屏和窗口还在原位。
画面怎么选
先用正在亮的主屏；只有一块健康的虚拟屏可以兜底。连上、断开都不会关掉或重排主屏、水冷屏和机箱小屏。
停在登录界面时
Moonlight 要先登录才行，这时用 ToDesk：看门狗每 2 分钟把 ToDesk 服务修回开着。重启后、登录前从别的设备真连一次，还没验收。
最近一次真实验证
10 月 8 日：同一网络里画面和操作都正常，切到手机热点后连续用 5 分钟没断（我确认的；同网延迟约 5–9 毫秒）。还没验过：连接中途断开后能不能恢复、电脑自然重启后能不能直接连回。这是那一次的实测，不保证所有网络都始终直连。

没画面看救急先看：串流没画面；技术细节见远程电脑串流。

让 AI 用电脑

电脑 MCP 本身不带模型：想事情的是发起的那个 AI（ChatGPT、Claude 或 Codex），电脑只负责照它的要求读文件、跑命令、操作桌面。

主机

家里的台式机

https://mcp.wly0829.cn/mcp

经 Cloudflare 隧道进来。文件、命令和桌面工具；普通、管理员、SYSTEM 维护都开着。

副机

笔记本

https://laptop-e48n0drj.tailbe620b.ts.net/computer/mcp

经 Tailscale 公网入口进来，单独登录、单独权限，用的是副机自己的文件和工具。

主机备用入口

经副机转接

https://laptop-e48n0drj.tailbe620b.ts.net/main-computer/mcp

主机的公网入口坏了才临时加上，干活的仍是主机。要单独授权一次，主入口的登录不能拿来用；两台都要开机联网。不会自动切换，也不会把中断的任务重做一遍。

平时 ChatGPT 里只留主机、副机两个连接。

ChatGPT 怎么接

账号要能用自定义 MCP（开发者模式）。

1
在电脑上打开 ChatGPT 网页：设置 → Security and login（安全和登录）→ 打开 Developer mode（开发者模式）。
2
打开chatgpt.com/plugins，点加号新建一个 MCP 应用，放进项目“我的电脑”，名字叫“主机 MCP”或“副机 MCP”，地址填上一屏那条。
3
认证选 OAuth，照下表填：
项目填什么
客户端 IDhttps://chatgpt.com/oauth/client.json
客户端密钥留空
令牌端点认证方式none
权限范围desktop:control
4
点连接，弹出电脑自己的登录页：输入密码中心里登记的“电脑 MCP 入口密码”，不是 OpenAI 的密码。
5
连上后先让它调用 ComputerContext，看连的是不是那台电脑，再跑一条只读命令。显示“已安装”不算连通。
在手机上用
手机 App 能不能直接新建连接还没核实；建不了就在电脑网页上给同一个账号加，手机上照样用。手机上用不用开 Tailscale：不用，ChatGPT 的服务器经公网连电脑，手机原来的代理照开。
授权弹窗一直转圈
关掉整个弹窗，从“连接”重新来一次，见救急先看：ChatGPT 授权转圈。

Claude 和 Codex 怎么接
Claude

现在登记的是主机上的 Claude Code 连副机，连接名 secondary_laptop：

1
在主机终端运行：

claude mcp add -s user --transport http --client-id claude-main-desktop --callback-port 33418 secondary_laptop https://laptop-e48n0drj.tailbe620b.ts.net/computer/mcp

2
在能交互的终端运行 claude mcp login secondary_laptop，在弹出的浏览器里登录；后台程序做不了这一步。
3
回调地址只能是 http://localhost:33418/callback，换成 127.0.0.1 或别的端口都会被拒。

Claude 连主机、Claude 的手机 App 和网页版连这两台电脑：目前没有登记过的接法。

Codex

主机的 Codex 用 secondary_laptop 连副机；副机的 Codex 用 main_desktop 经备用入口连主机。Codex 的回调是 http://127.0.0.1/callback，只允许端口变，和 Claude 的不能混用。

10 月 8 日那两次冷连接走的是两台电脑上现成的连接脚本（helper），不是 ChatGPT 或 Claude 客户端；它们说明当时两台电脑能互相维护，不说明电脑彻底卡死时还能执行。

这些是带日期的记录，不说明电脑此刻在线；此刻看页首“现在”。

用之前知道
  • AI 用鼠标、键盘时，占的是我正在用的桌面。
  • 电脑要开着、联网；没人登录时，桌面类工具用不了。电脑 MCP 救不了没启动的 Windows。
  • 连上电脑，不等于开了个人资料或无限制授权；Windows 管理员、SYSTEM 也不是我的最高授权。
  • 连不上先看救急先看：远程连不上。
