# 一套日常编辑主题

〔回到项目 → Typora 薄荷主题〕　〔GitHub〕　〔复制 AI 续作说明〕

Typora Theme Pack · 功能说明

让 Typora 的正文、标题、表格和代码有一致的阅读层次。

**当前情况：**Typora 的主题设置仍指向 Verdant Mint；两份主题文件都装着，但只有入口文件和源码一致，共享样式文件还少了 9 月 29 日加的表头底色一行，需要重装一次才算到位。编辑器里实际显示成什么样，这次没有打开确认。

## 这项功能怎样使用

用途与实际影响

## 为什么需要它

长文不仅需要颜色好看，也要区分层级；代码行若继承了外层卡片样式，会出现逐行圆角和背景错位。

## 举个实际例子

我在 Typora 里写一份有标题、表格和代码的说明。选择 Verdant Mint 后用同一套样式编辑，代码容器和每行文字保持各自结构。

## 最后我会得到什么

得到一套可选择的主题；导出给不同读者时仍能另选 PDF 样式。

## 正常时

两份主题文件都已安装并和源码一致；在 Typora 里手动选择后，再看正文、表格和代码的真实显示。现在共享文件不一致，还没达到这一步。

## 发现问题时

编辑器没显示新样式时先重开并确认选中了 Verdant Mint；verify 报告某个文件不一致，就重新运行 install。

## 入口不可用或证据不足时

没有可用的 Typora 时只能检查文件和样张，不能称原生编辑器画面已验收。

## 从哪里开始

运行 python tools/install_theme.py install 把 Verdant Mint CSS 放进 Typora 主题目录，重开后在主题菜单手动选择 Verdant Mint。

## 需要准备什么

- 要在 Typora 查看的一份文档

- 是否安装并选择 Verdant Mint

## 从开始到拿到结果

1. **安装主题文件**　工具只复制本项目 CSS，并为差异旧版保留备份。

2. **在 Typora 选择**　重开编辑器并手动切换到 Verdant Mint；安装完成不会自动激活。

3. **看真实文档**　检查中文、表格、代码和打印效果，发现问题再回到主题文件调整。
