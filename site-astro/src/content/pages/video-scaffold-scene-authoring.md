# 把旁白、真实素材和动画规则收进可审阅的 SVG 场景

〔回到项目 → 本地视频制作〕　〔GitHub〕　〔复制 AI 续作说明〕

video-scaffold · 功能说明

画面现在有三种做法。讲解视频默认写“图文页分镜表”：一个 JSON 文件说清每页放什么、每个元素在念到哪个词时出现，工具把它搭成画面；原来的逐场 SVG 路线照旧，工具整理提示，人或 AI 只做可审阅的小画面，公共动画模板让它动起来；独立网页作品则可以自由用 Canvas、SVG、WebGL 或网页元素创作。

**当前情况：**本期影片《电子雪貂饲养员》用图文页路线做完，已于 10 月 11 日 12:43 通过本人审定；新增的组件和工具这次没有逐个重新验证。

## 这项功能怎样使用

用途与实际影响

## 为什么需要它

让 AI 一口气生成整个播放页面，容易重复公共动画、跑错时间或引用根本不存在的素材。把画面拆成“分镜表里的一页”或“一场小画面”，既方便人审阅，也让版式、主题和播放规则只维护一份；缺项能在搭建时定位。

## 举个实际例子

我可以说：“第二页用我给的那张截图，框出右上角的按钮；念到‘三项变化’时依次出三张卡片，最后数字条长到 82。”系统把真实素材和说词时间写进分镜表，字会跟着念到的那个字出现，不会抢先。

## 最后我会得到什么

得到一份可读、可改的分镜表（或逐场画面片段）和能预览的画面。工具检查页次、重点词、文字时序和动画规则；具体画面是否准确、好看仍由人审阅。

## 结果怎么看

## 正常时

每页或每场画面已经审阅，元素出现的词能对上当前旁白，字不早于念到、动画放完才退场；检查通过后进入预览。

## 发现问题时

词重复、识别错或素材含糊时回到旁白与原图确认，不凭猜测把画面贴上去；字比念到早、动画没放完就退场，会直接被拦下。

## 入口不可用或证据不足时

缺分镜表、时间位置或画面片段就停止；明确不需要素材的页面仍可制作。

## 从哪里开始

讲解视频：配音和词轴就绪后，在影片目录的 pages 里写 JSON 分镜表，定义每页的版式和元素在哪个词出现。分镜路线：运行 `run.ps1 prompts`，按提示把每场 SVG 片段保存为 fragment_NN.svg。独立网页作品在 webfilm 里直接写作品。

## 需要准备什么

- 每页要表达的内容与画面要求

- 真实素材（图片、截图、录屏、标志）或明确无素材

- 需要对齐的重点词

## 从开始到拿到结果

1. **整理本页材料**　把原文、实际读到的重点词和选定的素材放在一起；没有素材的页也明确标出。

2. **写分镜表或画面片段**　图文页选版式和组件、写元素出现的词；分镜路线只保存这一场可审阅的画面。都要核对事实、布局和动画，不生成另一套不受控的整页程序。

3. **搭建前对齐**　工具检查页次、词和文字时序；缺页、重点词对不上、字抢在念到之前，都会停下。

## 技术实现与依据（一）

这里保留实现、关键条件、精确入口、历史记录和验证结果。

图文页分镜表、逐场 SVG 合同、组件与主题已在源码中；本期图文页影片已审定，新组件本次未逐个重验（内容核对到北京时间 2026-10-11 15:09 的最后一次提交 c4eec887）

## 关键规则与设计选择

1. 图文页和分镜路线生成的 SVG 遵守同一份合同：不带整页脚本和独立时钟；独立网页作品可以用 Canvas、SVG、WebGL、网页元素，只要求按绝对时间求画面、声音离线排好。

2. 字按实际念到的时间逐步出现，强调色不能早于底字；概括性字样要显式标 `summary:true`，重复前文原话时，原话必须在重现前已完整念过，不能借重现提前显示；后文词和负偏移要在当前词轴范围内说得通。

3. 高级动效仍必须是时间 t 的纯函数，不能因为预览能动就引入真实时钟；分镜 prompts 只整理提示，保存 fragment 才是创作动作。

## 当前怎样实现

- 图文页用 `pages/*.json` 读本期原文、真实音频/词轴和选定素材，PageBuilder 生成 SVG/HTML，复用分镜路线的搭建、布局检查和逐帧出片。

- 组件分两层：31 个顶层版式（8 个基础版式、22 种图解和卡片组），以及 17 种卡片内图解。基础版式包括页眉、说法堆叠、卡片组、时间线、带图标清单、数值条形、圆形擦除和网格卡片；图解包括流程/分派树、原话档案、层层把关、交接、闸门、结论胶囊、设备流、容量图、网页窗口、简介链接和互动按钮等。两层不能相加成“48 种动画”。

- `config.PAGE_THEMES` 集中定义白底绿和纸红两套主题，默认白底绿；字体、颜色、字号、留白和字幕样式都从这里读。白底绿是本项目的默认，不是所有创作的统一风格。

- 素材呈现：`screenshot` 贴完整原图；`screen` 可引用真截图，裁切、平移推拉，或把已有录屏按区间抽帧放进窗口播放；强调框和标注单独叠加；`brands` 登记已有标志图，组件用 `logo` 引用。只用本人或 AI 选定的实际文件，不自动截取任意应用，也不重画出来源文字。

- `author.py` 读取脚本和词轴，注入实际可用词串与素材地址，没有素材时明确写无；有 `scripts/visual-direction.md` 时把同一份主体、造型、配色、构图和动作目的用到各场，但不放松透明背景、定位与动画分离、绝对时间等通用合同。

## 技术实现与依据（二）

- `build_scene.py` 支持正常单/双引号属性、有限中文数字变体、data-cue-index 和 data-cue-offset；未命中或非法属性明确失败。

- `scene_base.html` 的 seekTime(t) 现有 39 个动画分支（原有 32 个，新增 drop、frames、iris、keys、mark、shake、wave）；这是去重后的运行时分支数，不代表 39 种都在真实影片里用过。

- `pipeline.image_jobs generate` 从图片清单生成标明“任务类型：生图”的派单和“计划中”回执，写明用途、提示、参考图和输出位置；`accept` 读取真实文件的尺寸和哈希并登记。generate 不调用模型，“计划中”不表示图已生成，登记也不能代替实际看图。

## 执行流程

1. 配音与词轴就绪后，写分镜表或运行 prompts。

2. 阅读本页原文、可触发的词与真实素材地址；无素材页面可以继续。

3. 人或 AI 选版式、组件、主题，或设计 SVG 片段，并按结构指南审阅。

4. 保存分镜表或按规范命名 fragment_NN.svg。

5. 搭建时强制页次与时间轴一致，解析触发词、检查文字时序并组合公共模板；已引用素材是否存在在出片身份阶段检查。

## 本模块用到的名词

| 名词 | 意思 |
|---|---|
| 图文页分镜表 | 一个 JSON 文件，写明每页用什么版式、放哪些元素、各在念到哪个词时出现；工具据此搭出画面。 |
| fragment（场景片段） | 分镜路线里只放在公共 SVG 舞台内部的本场内容，不重复整页运行时。 |
| data-anim（动画原语） | 声明元素随时间如何出现、移动或变化；实际状态由 seekTime(t) 计算。 |
| file URI（本地文件地址） | 把明确素材的绝对路径编码给浏览器使用；没有素材就明确写无，不虚构。 |

## 专业定义

分镜表和提示只准备证据与结构；画面是否准确、好看必须由人或 AI 审阅。

解决什么

防止模型生成失控页面、素材引用凭空出现，以及动画表面正常却和旁白没有可追溯关系。

## 边界

- 组件库和主题提供画面能力，不替人判断事实、审美和信息层级；没有自动审美或事实判断。

- 静止主内容超过 3.5 秒只提示；有限动作结束后默认再停 0.25 秒才退场。词轴估计或词内插值的误差仍需听音与有声预览修正。

- 旧定制生成器和封面只留在 Git 历史，不是当前入口；本期生成的图片和成品留在影片目录，不写进通用源码。

## 失败与恢复

| 情况 | 怎么处理 |
|---|---|
| 片段或分镜表含指南禁止的结构，或字早于念到 | 重复属性、未知动画、非法时间、文字抢先和动画未放完就退场由搭建阻断；其他内容与视觉问题由人或 AI 退回修改，不把合同通过说成完整美学验收。 |
| 触发词没在时间轴里找到 | 明确阻断搭建和核对；先核对音频与词轴，选真实词语、出现次数或偏移，再重建和听看。 |
| 已引用的素材路径不存在 | 提示阶段不虚构，出片身份读取素材时直接失败；没有引用素材的页面不因此失败。 |
