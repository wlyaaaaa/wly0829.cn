# 新站组装

新版源码已经迁入本仓库的 `site-v2/`，不再从缓存目录读取。仓库根运行 `npm run build` 生成 `dist/`，包括原样保留的实况四页；预览运行 `npm run preview -- --host 127.0.0.1 --port 5194`，不用旧缓存的8829启动脚本。

- 组装设置：`站点设置.json`。
- 只组装新版画面：`python -B -X utf8 site-v2/site-assembly/组装.py --output <单独输出目录>`。
- 检查完整成品：`python -B -X utf8 site-v2/site-assembly/组装.py --只检查 --output dist`。
- 更新注意事项与私有输入：见仓库根 `docs/update.md`；按需更新流程仍待本人定。
- 扫描与发布：见仓库根 `docs/publish-and-scan.md`。本工具只操作本地成品，不上传。
