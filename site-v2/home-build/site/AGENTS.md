# 根首页 `/`

开站先进入带动效的个人工作台：从画面、副屏和按钮看此刻状态，并去各个入口。

共用要求见[仓库规则](../../../AGENTS.md)、[产品与内容合同](../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../docs/design/layout-and-interaction.md#首页开场播放与等待)和[本机私有内容规则](../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 首屏保持定稿的样子：机箱、窗外日落、亮着的机箱小屏、右侧状态卡和副屏。（M082、M087）
- 往下滚到下一屏时，状态不闪黑。（M082、M087）
- 首屏的画幅和上下的模糊边保持现在的样子。（汇报页「首页第一屏：上下留模糊边，还是铺满」14:31，本人选“保持现在”）
- 保留日夜切换。（布局与交互「插画／昼夜」）
- 每次打开都照播白纸晕开；第一帧和外观照定稿，优化只许提速。（布局与交互「首页开场／播放与等待」）
- 按下和松开时，按钮上的字都看得清；真实入口照常点得开。（M085、M237）
- 在线时副屏显示四格真实读数，温度标明是 CPU。（M088、M089）
- 副屏每格点了去对应的实况页。读得到后台、读不到后台两种情况，每次发版前后都实点读数和跳转。（M202；汇报页「根首页的后台读数和副屏跳转是红线」09:26）
- 实时按钮下面那行和副屏，都要分开“连不上”和“关机了”。首页没有弹窗。（M1189；汇报页「根首页两处要分开‘连不上’和‘关机了’」2026-11-28 05:12）
- 副屏连不上显示四格横线；关机显示三格横线，最下面写“关机了”。（M1189）
- 任何情况下（连不上、等数据、读得慢、夜里、手机上），副屏照平常的样子显示、动效照播，不出现紫色底、星星、月亮、灯带不亮、读数停住的画面。（M477）

## 不许做

- 本人原话“首页禁止用云端缓存”：根首页不放云端存的读数。（M1189；汇报页 OFFLINEDESIGN1127C，2026-11-27）
- 瀑布、机箱灯、按钮弹出等动效的定稿参数不许改。（M083、M086）
