# 一类备份 `/live/backup/?id=…`

查一类资料有哪些副本、最后什么时候备成、哪些日期真能恢复，以及失败或等待卡在哪个位置。

## 已定（照做，不再问本人）

- 首屏先摆这类备份的现况和实有副本在哪；下面再看核对、恢复点、待传和失败项。（M050、M781）
- 每个位置各写份数、大小、内容日期、核对时刻和最近结果。（M292、M378、M849）
- 原件位置和备份位置分开标。（M849）
- 恢复点列真实可用的日期和核对结果；单个坏点单列，不连累同组已确认的点。（M114、M521）
- 点某个恢复点能找到那一份的详情。（M361）
- 结果照原备份结果分四档：齐全；少量跳过的“大部分成功”；较多没成的“部分成功”；整份失败。（M780、M907）
- 有问题写清哪一份、何时发生、原因、现在处理到哪。（M780、M907）
- 访客看得到能公开的副本位置、时间、大小和结果；文件名照现行公开边界判断。（M858；全局规则「对外公开的边界」）

## 不许做

- 暂时读不到，不写成“没有副本”。（M849、M1258）
- 不拿一次运行退出，代替真实可用的恢复点。（M114、M521）
