# 智能体开场 `/live/agents/opening/`

看三家开始对话时实际读进去的规则文件，和额外补到眼前的内容。

共用要求见[仓库规则](../../../../AGENTS.md)、[产品与内容合同](../../../../docs/design/panel-content-contract.md#public-content-gate)、[布局与交互](../../../../docs/design/layout-and-interaction.md#实况入口和本人操作)和[本机私有内容规则](../../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 默认显示 Claude 页签。（M919、M1059）
- 按宿主实际加载的顺序和边界，展示三家的入口内容、实际路径和字数；能切换不同的开法。（M919、M1059；定稿卡「自动任务和AI账本」§13、§14）
- 分清哪些和规则页共用、哪些是本家独有、哪些是程序另补的。（同上）
- 额外补进来的文字取最近一次实际输入，保留能公开的事实。（M1109；定稿卡「钩子清单」「每条都要跟着做的」）
- 访客版只把会暴露的片段或字段按公开边界处理。没采到的照实写没采到。（M1109）

## 不许做

- 不做逐场记读取规则文件的常驻追踪。（定稿卡「钩子清单」§十；定稿卡「自动任务和AI账本」§9）
