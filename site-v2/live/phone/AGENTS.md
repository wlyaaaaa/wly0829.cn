# 手机 `/live/phone/`

看手机还连着没有、什么时候怎么用、上网走哪路、装了什么，以及电池和空间。

共用要求见[仓库规则](../../../AGENTS.md)、[产品与内容合同](../../../docs/design/panel-content-contract.md#public-content-gate)、[布局与交互](../../../docs/design/layout-and-interaction.md#实况入口和本人操作)和[本机私有内容规则](../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 手机真没网或关机时，用上次取到的值并写时刻。（M023、M923）
- 离线时能采的先存在手机上，联网后补传。（M923）
- 在线却缺该有的采集，算故障，修来源。（M1198）
- 「上网和流量」沿用原来的时间带样式，固定四项：Wi-Fi、SIM1、SIM2、没记录。（汇报页 NETLEGEND1128，2026-11-28；M1199、M1200）
- 没用到的项写 0 分钟；连着 Wi-Fi 时照实际连接显示 Wi-Fi。（NETLEGEND1128；M1268）
- 手机用法时间带的各种状态都能点亮看清。（M276）
- 有设备记录证明关机的，画成关机段；灭屏、断网和缺记录各自分开。（M641、M1201）
- 「装了什么」的近 7 天变化分清安装、更新、卸载。（M642）
- 卸载来源修好以前、没记下来的旧行省去。（M772）
- 电量、温度、机型、存储、内存各取各自的真实读数；首屏不重复抄同一个电量或次数。（M640、M652、M653）
