# 项目详情页 /live/project/

所有项目的详情页共用这一套程序（page.js、look.css、layout.js、interface.*、additions.js、documents.js 等），改一次所有项目页一起变；各项目自己的件（如 site-readings.js、pcconfig.js、media.js）只管那一页。

改哪个项目页，先读本说明，再读 decided/<项目 id>.md（有就读）。访客版整项不显示的项目，那份放在本机 docs/design/private-decided/<项目 id>.md，不进仓库。共用要求见[仓库规则](../../../AGENTS.md)、[产品与内容合同](../../../docs/design/panel-content-contract.md#public-content-gate)、[布局与交互](../../../docs/design/layout-and-interaction.md#实况入口和本人操作)和[本机私有内容规则](../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 两版一套：本人版和访客版是同一个页面、同一套后台，访客看到的不同只来自后台按看的人给的数（遮挡、换说法），按钮两版一样。（汇报页「个人项目页」11-28 02:26）
- 访客版版式跟本人版一样，只把具体的数和标题换成 ••••，原地挂紫色“访客看不到”，不把整块换成一句话；能点进去的条目外面不挂标签，点进去是做好的那页。（汇报页 11-27 05:43；VT1，11-27 14:17）
- 访客口径只放宽、不收紧：往开里放不用问，要多藏一样先问本人。私事只照定稿卡认定，定稿卡没写的不往私事里猜，拿不准照原样。（定稿卡「私事」；本人 11-28 17:40）
- 来源不同、更新日子不一样的数，各写各的日期。（汇报页 11-27 05:50）
- “旧了”看源头有没有新数没取到，不看隔了多久：源头真没变的照常显示日期、不挂“旧了”；每样数用哪种更新方式由 AI 定。设计图上的“旧了”只是演示，实际页面不能真旧。（汇报页 11-28 04:58、04:32）
- 全站文档和代码的“X 万字”都数空格以外的字符（Word 的“字符数（不计空格）”）；凡写“代码 X 行”的地方，先写“代码 X 字”，下面再写“代码 X 行”。（CC2，11-28 13:20；汇报页 11-28 05:31）
- 每页三块的顺序：全部变化 → 本地还没推的改动 → 成品；“全部变化”和“成品”都分近 7 天、近 30 天、全部，先少后多慢慢展开。（本人 11-24 20:34，M766）
- 二级页、弹框、展开和收起后，跟第一页一样好看。（本人 11-28 14:55）
- 不另做手机版：手机就是电脑版等比缩小，窄的只顾电脑竖屏。（汇报页 11-28 05:40）
- 项目页为了合理可以适当重复；别的页已有的，优先跳转联动，要不要双向由 AI 判断。（汇报页 11-28 05:03）
- 冻结的项目共用一张“冻结档案”卡，冻结时算一次存下来；不深入调查，最多做统一组件。（FZ1，11-28 05:44；汇报页 11-28 04:35）
- 页面上的字由 Claude 写，GPT 只接线；好不好看要有没参与的 Opus 看过，成批可以抽查，不能为零。（本人 11-28 17:38，主控转）
- 改样子先出最终图（本人版、访客版）给本人看，他点了才施工；为了实况页可以顺手完善项目、修项目的毛病，但这不是不看最终设计就开工的授权。（汇报页 11-27 06:20；11-28 04:35）

## 不许做

- 访客版和公开页面不许写得像本人没在工作，不说资料是编出来的，不说合成演示；本人版的数照旧显示。发版文字核连注释一起扫。（本人禁令，汇报页 11-28 04:29；管到哪里见 06:03）
- 不出培训机构的名字，一律叫“课程参考”或“课程”。（汇报页 11-28 02:20）
