# 通知发送回执 `/live/notifications/`

看提醒到没到、哪条卡在哪一步，分别核对手机和邮件的真实投递结果。

## 已定（照做，不再问本人）

- 首屏先说发了多少、到了多少、哪些没确认；用同一时段的数，列出差额和卡在哪一步。（M063、M278、M501、M1147）
- 没确认的写明缺哪种回执，按证据和真没到分开。（M278、M501）
- 同一件提醒合在一起看各渠道：手机弹没弹、邮件确认没确认、是不是都没确认，以及系统记下的实际原因。（M306、M1147）
- 「具体是哪几次」默认给一部分，可再展开。（M773）
- 「全部记录」默认展开，可以继续往前查；从别的页点历史直达列表。（M1218、M1285）
- 手机横幅第一行写实际对话名，第二行一句话说清发生了什么。（M395、M669）
- 访客记录保留能公开的事实和各渠道结果；受限内容只在命中处处理。（定稿卡「等你的事」第一节；定稿卡「私事」「每个地方怎么给」）

## 不许做

- 还缺回执的，不写成已收到。（M278）
- 邮件没确认而同一件手机已到的，不合成两件失败。（M306、M501）
