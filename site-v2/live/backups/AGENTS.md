# 备份 `/live/backups/`

一眼看清各类资料的副本、防护缺口和能恢复到哪一天，再从总表进去查具体副本。

## 已定（照做，不再问本人）

- 资料类别按重要性固定排序；类别增减或改名时，同时改网页登记。（M782、M849）
- 总表先交代哪些已备、哪些在等、哪些要处理。（M365、M781）
- 恢复区按类别读；恢复点的名字和先后跟单类详情一致。（M419、M781）
- 大小和日期写明是哪份副本、什么时刻的数据。（M849）
- 不实时、不定时采的数，登记进更新网页时要核的清单，首屏大表也跟着更新。（M849）
- 结果照真实源头分：少量跳过是“大部分成功”，较多没成是“部分成功”，全部没备成才标“失败”。真故障交自动修理。（M780、M907）
- 从首页点某类备份的问题，直达对应条目；点一类进详情；返回时保留原来的筛选和位置。（M115、M357）
- 访客照给能公开的时间、大小和结果；文件名照现行公开边界判断。（M858；全局规则「对外公开的边界」）

## 不许做

- 跳过部分文件的任务，不整个标失败，也不写成全齐了。（M607、M780）

## 还没定（要问本人）

- 成功和没备成刚好各半，或文件数只有估计值时，“大部分成功”和“部分成功”的界线怎么分。（M907）这是技术细节，AI 可先照原备份结果判断；会改变本人看到的分档时再问。
