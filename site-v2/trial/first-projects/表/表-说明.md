# 三张全站共用表：说明

北京时间 11-13 写（Opus 子代理，给施工主持）。

## 各管什么

- **`归属表.md`**：每个项目、技能、子页挂在哪、做到哪（状态）、页上称呼“我”还是“用户”、项目大小、碰不碰私事；外加“几件事各在哪一页讲”“暂缓的页”“可能改动多的技能”三节。中文名照抄 `../叫法表-名字.md`，叫法表改了名，这里跟着改。
- **`人话词表.md`**：常用词（页上要用、说法要统一，第一次出现带那句）和行话（页上尽量不用，配一句换成什么）。
- **本页**：怎么用、程序怎么读。

## 写稿的怎么用

- **只读不改。** 想加词、想换说法、想另开子页、觉得某个技能该挂别处，写进交回，主持定了再改表。
- 开写前在归属表里找到自己的项目和它挂的技能：状态是“要做”的才写；称呼按那一列，一页一种；备注和“几件事各在哪一页讲”里指去别处的事，只写一句带上〔名字〕，不搬过来讲。
- 指向暂缓、不进流水线、不上网站、待本人定的页，不放按钮，左下角空位照留；按钮去向只能是表里的中文名，或“接实况入口”。
- **称呼细则：** 页上不写“你”“本人”。“用户”页提到网站主人自己的东西，用不带称呼的说法（“这个网站的驾驶舱”“网站上另一个项目〔电脑大本营〕”），不写“我”；“我”页不用“用户”指自己。引号里的原话（跟 AI 说“我要换机恢复”）、指 Windows 账户的“用户”不算。
- 常用词每页第一次出现带上那句，后面不再带；那句可以按页面顺一顺，意思不变。

## 程序读哪几列

表都是一行一个东西、列名固定。

| 文件 | 表 | 读哪几列 |
|---|---|---|
| 归属表 | 项目表 | 项目ID、中文名、状态、称呼 |
| 归属表 | 技能表 | 技能ID、中文名、归属项目ID、状态、称呼 |
| 归属表 | 子页表 | 子页名、归属项目ID、状态 |
| 人话词表 | 常用词 | 词、别名（页上不用）；别名用“、”分开，“—”是没有 |
| 人话词表 | 行话 | 词、说成什么 |

扫什么（只提醒，不拦）：
- 〔〕里的名字都能在三张表的中文名、子页名里找到；指向的那一行状态不是“做完”“要做”的，提醒“这里不该有按钮”。“待起名”“—”不算名字。
- 每页的称呼和表里那一列对得上；“你”“本人”是 0；“用户”页出现“我”、“我”页出现“用户”就提醒（引号里的除外）。
- 每个技能ID 在技能表里只有一行、只有一个归属项目ID。
- 页上出现常用词的别名、或行话，就提醒，附上“说成什么”。认词时先认最长的（“代码仓库”先于“仓库”，“镜像链”先于“镜像”），〔〕里的名字和常用词“词”那一列先认出来、不再当别名或行话；拉丁字母按整词、分大小写；行话表“备注”里写了不算的情形，程序可以先不管，留给看提醒的人判。
- 源码链接只指向公开仓库：公开不公开现场去 GitHub 查，表里不记，免得过时。

## 谁改、改了怎么办

- 只有施工主持改这三张表；改了就在流水线下一步之前生效，已做完的项目按流水线想法第 3 节用程序重扫一遍，命中的再改。
- 状态从“暂缓”“不进流水线”“待本人定”改成“要做”，回头把原来该指向它的按钮接上（暂缓页的按钮清单写在归属表“暂缓的页”）。
- 大小只用来排批次、估时间，不定一个项目分几页。
