# 用法

在 `trial/first-projects/` 运行（Python 3，仅用标准库）：

- 状态：`python -B 工具/project_status.py`；写入 `工具/状态表.md` 和 `工具/状态表.json`，JSON 的 `projects` 数组可供汇报页读取。
- 填单：`python -B 工具/fill_order.py localocr order-清点-通用单.md`；生成 `localocr/order-清点.md`，已有文件报错退出，屏幕列出剩余〈〉及行号。
- 一致扫描：`python -B 工具/consistency_scan.py`；照共用表扫所有正式内容稿和可识别出图提示，只写 `工具/一致扫描.md`、`工具/一致扫描.json`，不改稿；支持 `--root`。
- 扫描测试：`python -B -m unittest discover -s 工具 -p test_consistency_scan.py -v`；“未识别”列提示需要人看的局部改图或页名，旧版本提示也会计数。

填单支持清点、项目页、对页、读者单、去向核对、做成网页六份通用单；加 `--output-root E:/Cache/Codex/Temp/试跑目录` 可把项目目录放到临时位置。两个命令都可用 `--root` 指定清单和模板根目录，默认按脚本位置定位，无须改工作目录。

状态按非空产物识别，图片仅统计 `图/页名-NN-vK.png`，同一页名和编号只算最大版本；背景、整页长图不计张数。应出数只读取内容稿开头“分层”表的“几张图”。网页优先数 `网站示意/英文短名/` 中非空 HTML；没有时才数项目旧 `网页示意/` 直属 HTML，避免重复计算。文件时间直接转 UTC+8，与本机时间加15小时等价。

“补稿”凭非暂缓的内容稿留底识别；“照读者单改”凭当前内容稿比最新读者单晚识别，不能证明实际采纳了意见。看不出应出图数时显示“认不出”；没开工的应出数显示“—”。表1的候选项目也列入状态表，不代表加入发布范围。

填单只改“这一次”，其余正文保留原样（正文里的〈〉也会列出）；画风、哪一趟、已做相关页等留给主持判断。归属技能照全站清单表3，不替主持决定哪些上站。测试：`python -B -m unittest discover -s 工具 -p test_tools.py -v`。
