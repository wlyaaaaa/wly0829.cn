# 随身桌面讲解页

查如何接入自己的桌面，远程画面卡住时到底由哪条链路、屏幕与配置决定。 本目录里的总览、模块和技能页沿用同一份说明。

共用要求见[仓库规则](../../../../../AGENTS.md)、[产品与内容合同](../../../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../../../docs/design/layout-and-interaction.md#项目和技能讲解页画里的按钮)和[本机私有内容规则](../../../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 讲清实体主屏优先与唯一虚拟屏兜底、窗口归位、独立显示参数、显卡故障、链路恢复及何时要人在设备旁。（产品与内容合同「Project expansion gate」）
- 把本机检查、设备之间的连接、真手机操作、物理屏切换及冷启动的证据分别说明。（产品与内容合同「Project expansion gate」）

## 不许做

- 不放真实接入地址、设备身份或凭据。不为补这页做真机破坏性演练。（产品与内容合同「Project expansion gate」）
