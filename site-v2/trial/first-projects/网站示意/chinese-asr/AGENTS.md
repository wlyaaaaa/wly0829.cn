# 中文速记员讲解页

从说话到拿到可校对的文字，查怎样接入口、何时转写、何时需要核对说话人与时间。 本目录里的总览、模块和技能页沿用同一份说明。

共用要求见[仓库规则](../../../../../AGENTS.md)、[产品与内容合同](../../../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../../../docs/design/layout-and-interaction.md#项目和技能讲解页画里的按钮)和[本机私有内容规则](../../../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 说清中文转写走的真实入口、任务和模型路线，分开讲源码、测试、依赖、实跑、基准与人工校对的证据。（产品与内容合同「Product boundary」）

## 不许做

- 不放私人音频、转写原文、声音向量、模型权重或云请求内容，不把匿名分组或本机线索写成身份确认。（产品与内容合同「Product boundary」）

## 还没定（要问本人）

暂无。
