# 共用设备信任弹窗

访客点本人操作时解释设备信任限制，保留本人在可信设备上的正常办理路径。

共用要求见[仓库规则](../../../AGENTS.md)、[产品与内容合同](../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../docs/design/layout-and-interaction.md#实况入口和本人操作)和[本机私有内容规则](../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 公开版和本人版是同一套按钮：不是可信设备的点本人操作，弹窗说明这台不是可信设备、只有本人能操作；可信设备照服务允许的继续办。不另做验证码、临时配对之类的第二套流程。（本人禁令，11-24 14:16；M133、M219；汇报页「公开版和本人版不做两套」）
- 确认框、失败和结果提示浮在页面上方，滚动时留在屏幕上，走完自己消失。（M1252、M1255；汇报页「全站弹窗」2026-11-28 13:48）
- 结果按后台真实确认显示，后台没回之前最多写“已提交、等结果”。（M981）
