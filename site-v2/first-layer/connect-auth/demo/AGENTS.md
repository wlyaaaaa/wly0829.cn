# 连接电脑 /mcp/ 与授权与状态 /computer-access/

连接电脑页告诉 AI 或本人怎样连到电脑。授权与状态页让本人确认设备信任、资料锁、授权和系统状态，再走实际可用的操作入口。

共用要求见[仓库规则](../../../../AGENTS.md)、[产品与内容合同](../../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../../docs/design/layout-and-interaction.md#实况入口和本人操作)和[本机私有内容规则](../../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

连接电脑 /mcp/：
- 保留已定样式，只把可用的入口用绿色突出一点（本人：“最多连接电脑绿的更明显一点”）。（M052、M053）
- 固定接法（地址、认证、客户端）先画出来，不等状态；地址、认证、客户端和命令以现行登记为准。（M239）
- 每个平台按钮都要真能打开对应接法或复制对应信息。（M448）
- “在线”这类连通状态和固定接法各写各的来源，状态写清怎么测的、多久算失效。（M1073）

授权与状态 /computer-access/：
- 个人资料、无限制授权、Windows 三格各自独立，个人资料锁和无限制授权不混在一起。（M1074）
- 每格标自己读到的时刻，没有就写这一格时间未知。（M1074）
- 个人资料锁上后，解锁入口仍在。（M132）
- 能不能办以设备是否可信和服务返回为准：可信设备照常办，别的设备弹全站统一的说明。（M133）
- 结果按后台真实确认显示，成功要等服务确认；略过、失败照实写。提示浮在页面上方。（M981；汇报页「全站弹窗」2026-11-28 13:48）
- Windows 格的锁屏：点“锁屏”，这颗按钮原地滑开变成“确认锁屏”，旁边照旧是“解锁”，始终只有两颗；4 秒不点就滑回“锁屏”。点“确认锁屏”才真锁，等后台确认了才写已锁屏。（汇报页 M1153LOCK1128，2026-11-28 21:04；M1153）
- 电脑关机时照第 7 对：顶上写“电脑关机了，这是某时的数据／电脑开机后才能用下面的按钮”，三格显示那时的状态，按钮变灰。根首页的离线样子归根首页，不在这里改。（汇报页 OFFLINEDESIGN1127C，2026-11-27）
