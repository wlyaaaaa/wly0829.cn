# 规则 /rules/

从常见情形查现在的约法和专题，再往下读条件、例外、版本及来源。

共用要求见[仓库规则](../../../AGENTS.md)、[产品与内容合同](../../../docs/design/panel-content-contract.md#public-content-gate)、[布局与交互](../../../docs/design/layout-and-interaction.md)和[本机私有内容规则](../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 整个 /rules/ 是一个规则工作台，显示当前已核验的规则版本、上一版指向和完整发布清单。（产品与内容合同「Public-content gate」）
- 页内专题选择跟着当前版本的主专题走。兼容别名和入口模板只留在完整清单里，不另列成专题。（产品与内容合同「Public-content gate」）
- 读者先看到常见情形：结论、什么时候触发、系统怎么做、要本人做什么、例子。（产品与内容合同「Product boundary」）
- 第二层可展开，保留条件、例外、失败处理和恢复。（产品与内容合同「Product boundary」）
- 技术依据（版本、校验、路径、完整清单）单独一层，默认展开。（产品与内容合同「Product boundary」）
- 右栏“钩子”直接跳到实况智能体页的钩子区 `/live/agents/#hooks`（本人：“钩子我之前定跳转到智能体的钩子页”）。（M1115）
- 约法和专题字数按非空白字符数，和智能体页同一个数法。（M1282）
- 页眉的本人版切换按钮只写“公开版”，左边一个切换图标；点了图标转起来，切换完停下复原，别用刷新图标。（M1151）

## 不许做

- 不另建规则详情页的单独路由，不把别名做成重复的阅读专题。旧版材料只能作为恢复用的历史出现。（产品与内容合同「Public-content gate」）
