# 项目与技能列表 /projects/、/skills/

项目页用卡片找真实项目和各自的讲解，技能页用同类用途找能叫 AI 做的事。两页共用列表源码。

共用要求见[仓库规则](../../../../AGENTS.md)、[产品与内容合同](../../../../docs/design/panel-content-contract.md#product-boundary)、[布局与交互](../../../../docs/design/layout-and-interaction.md#卡片跳转主要去处与多指向)和[本机私有内容规则](../../../../docs/design/private-content-rules.md#网站项目私有内容规则)（存在时）。

## 已定（照做，不再问本人）

- 项目按已定顺序出卡，AI 百工谱第一、电脑大本营第二。已定大卡占整行，其余照现役并排方式。首屏直接看到卡片，卡片正文进入讲解，原有明确模块入口各去各处。（站点设置「项目先后」「大卡片」；产品与内容合同「Product boundary」）
- 技能按用途交错排，同一行两张讲相近的事，同项目尽量不相邻。保留已定顺序，增补只放到合适位置。鼠标停到某张时仍能认出同门技能。（站点设置「技能先后」，本人 2026-11-17 05:58、06:13）

- 可公开项目的仓库按钮用官方 GitHub 标记和已登记地址，私有项目显示相应状态。已退役项目按登记留档和交代去处。（产品与内容合同「Product boundary／退役内容的去处」）
